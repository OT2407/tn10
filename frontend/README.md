# TN10 Creative Economy Frontend Skeleton

This folder contains a React + TypeScript + Tailwind UI architecture skeleton for:
- Explore feed
- Item detail
- Contract workspace
- Collaboration creation/revenue split
- User/Seller/Admin zone components

## Structure
- `src/pages`: page entry components
- `src/components`: reusable modular UI pieces
- `src/mocks`: realistic dummy data
- `src/types`: strict prop and domain typing

This is intentionally isolated from backend build scripts.
